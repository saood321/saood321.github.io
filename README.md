# Muhammad Saood Sarwar — personal website

Files:
- index.html  — page content (bio, research, experience, education, contact)
- style.css   — design, colours, light/dark theme
- script.js   — publications list (edit the `publications` array to add papers), filters, search, theme toggle, hero animation
- profile.jpg — portrait
- Muhammad_Saood_Sarwar_CV.pdf, Muhammad_Saood_Sarwar_Publications.pdf — downloadable files

## Free hosting on GitHub Pages
1. Create a GitHub account and a new public repository named `<your-username>.github.io`.
2. Upload all files in this folder (keep index.html at the top level).
3. Go to Settings → Pages, set Source to "Deploy from a branch", branch `main`, folder `/root`.
4. Your site will be live at https://<your-username>.github.io within a few minutes.

Alternative: drag this folder onto https://app.netlify.com/drop.

## Updating the CV
Replace Muhammad_Saood_Sarwar_CV.pdf with the new file, keeping the same name.

## Moving to a custom domain later
Buy a domain (e.g. saoodsarwar.com), then add it under Settings → Pages → Custom domain and follow GitHub's DNS instructions.
